# BeatSync – Beat Marketplace

## About the Project
BeatSync is a web application developed as an individual Software Engineering project at Fontys University of Applied Sciences.

The platform allows music producers to upload and sell their beats, while artists can browse, discover and purchase beats with different licensing options.

## Features
- User roles for producers, artists and administrators
- Upload and manage beats
- Browse and filter beats by genre, BPM, key and mood
- Beat licensing options, including exclusive and non-exclusive licences
- User authentication and account management
- Beat likes, follows and reporting functionality

## Technologies
- **Backend:** C#, ASP.NET MVC
- **Frontend:** HTML, CSS, JavaScript
- **Database:** Microsoft SQL Server
- **Architecture:** Layered Architecture (MVC)
